# Code of Conduct

Neighborline adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. It applies in all project spaces (issues, pull requests, discussions, and any event or
channel where someone represents the project) and to everyone who takes part.

The short version: be kind, assume good faith, welcome newcomers and people whose first language is not English,
and never harass anyone.

This project exists to serve neighbors in hard moments, many of them immigrants, elderly, or not fluent in English.
Please extend the same respect to the people described in issues, test fixtures and demo scenarios: describe needs,
not people.

## Reporting

Report unacceptable behavior privately to the maintainers at **conduct@neighborline.example** *(placeholder: the
maintainers will replace this with a monitored address before the repository is promoted)*. Until then, contact the
repository owner, [@Aaaaarin](https://github.com/Aaaaarin), privately through GitHub.

All reports are reviewed promptly and kept confidential. Maintainers follow the
[Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
(correction, warning, temporary ban, permanent ban).
